1

Create Flask application

Flask(__name__) creates the application object and establishes the application context.

2

Load environment-backed configuration

app.config.from_object(Config) installs database, Keycloak and Anthropic settings.

3

Initialize persistence

db.init_app(app) attaches the shared Flask-SQLAlchemy extension.

4

Install cross-cutting middleware

Identity resolution runs before requests; HTTP integration logging starts and completes around each request.

5

Register user-facing and API routes

Authentication, web UI and REST API blueprints become part of one Flask process.

Application factory benefit

The factory keeps construction explicit, supports tests, and prevents extensions from binding to a Flask instance at import time.

def create_app():
    app = Flask(__name__)
    app.config.from_object(Config)
    db.init_app(app)
    import models
    app.before_request(resolve_identity)
    app.register_blueprint(auth_bp)
    app.register_blueprint(web_bp)
    register_api_blueprints(app)
    return app

if __name__ == "__main__":
    app = create_app()
    app.run(host="0.0.0.0", port=port, debug=app.config["DEBUG"])
